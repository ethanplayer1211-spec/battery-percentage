Where does your battery % come from?

A browser-based simulation of how a phone turns electrical measurements into the battery percentage you see.

Open the interactive demo

The question

We use the number in the corner of the screen to decide when to charge. That number is itself an estimate. Inside the phone, a fuel gauge works out how much charge is probably left and passes the result to the software that draws the status bar.

What you can try

Start with Check battery. After 10 minutes of simulated use, the gauge reports 42%. Then set Time spent using the phone to 0 min, leave the resting voltage at 3.816 V, and run a second check. 47% is the estimate at the start of both runs. The first run spends 140 mAh before the check, and the second spends zero.

X-ray reveals the phone internals. The Power path and Data path toggles help you follow current and readings separately. Detailed version adds explanations alongside the key numbers.

What the code computes

  1. Measure. Divide the voltage drop across a 10 mΩ shunt by its resistance to estimate current.
  2. Look up. Interpolate between measured values for one lithium-ion cell to estimate the starting charge from resting voltage.
  3. Count. Add up current × time over the sample intervals and subtract that charge from the starting amount.
  4. Calculate. Divide the remaining charge by the modeled full capacity of 3,000 mAh. In the default run, about 1,273 mAh remains, or 42.45%.
  5. Report. Round the estimate and pass the whole percent to the simulated phone display.

The lookup points are derived from lab measurements of one lithium-ion cell. The default 3.816 V input falls between 3.79325 V (40%) and 3.841219 V (55%), giving a starting estimate of 47.11%. The input readings and cell capacity are simulated. The under-load voltage illustrates voltage sag. The estimate uses the resting voltage and the current log. The model runs entirely in the browser.
